# Seedcore 3D 애니메이션 파이프라인 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. 이 문서가 파이프라인의 단일 진실 원천 — 컨텍스트가 초기화돼도 여기서 재개한다.

**Goal:** 스프라이트 레퍼런스 → 3D 모델+리깅+클립 → N방향 스프라이트 시트 사전 렌더 → Pixi 프레임 애니메이션.

## 확립된 파이프라인 (플레이어로 검증 완료)

1. **클린 레퍼런스**: 무기·돌출물 없는 전신 직립 이미지를 `gen-assets`로 신규 생성 (편집 API로 원본 수정은 뭉개짐 — 금지). 무기는 별도 이미지.
2. **생성**: `node --env-file=.env tools/gen-3d.mjs <id> <클립,...>` — 이미지→3D→리메시(3만)→리깅→클립. 태스크 캐시(`assets/3d/*.tasks.json`)로 재실행 시 완료 단계 스킵. 무기는 `norig` 모드(모델+리메시만).
3. **클립 선택 주의**: Idle(0)은 두리번 회전 → **Idle_02(11) 사용**. Attack(4)은 루트 이동·깊은 숙임 → **Left_Slash(97) 사용**(제자리). 새 클립은 정면 고정 3프레임 검사 후 채택.
4. **정적 캘리브레이션 (필수)**: 클립 없는 리깅 GLB로 4방향 스트립 캡처 → 정면(yaw 0) 확인. 회전 모션이 검증을 오염시키므로 방향 기준은 반드시 정적 모델로 잡는다.
   실측 공식: **yaw = π/2 − 화면각** (three.js y-업 ↔ 화면 y-다운 반전).
5. **캡처**: `tools/preview3d.html?glb=...&weapon=...` 로드 → `__captureSheet(frames, cell, pass, dirs)` — 행=방향, 열=프레임, pass는 char/weapon 분리(무기 교체 설계). Playwright evaluate의 filename 저장 → `node tools/decode-sheet.mjs <txt> <png>`.
6. **통합**: `src/render/anim.ts`(시트 슬라이스·dirFromAngle 보정 상수 없음), 렌더러에서 상태(대기/걷기/공격)·방향별 프레임 교체. 루프 클립은 tick 구동(히트스톱 동기).
7. **무기 부착**: RightHand 본, 그립 상수 `(0,6,0) / (-0.35,0,0.55)` — preview3d.html 기본값.

## 현재 상태 (2026-08-01)

- 플레이어: 16방향 × 대기(Idle_02)/걷기(30)/슬래시(97) 완전 통합·배포. 조준 링 네비게이터 포함.
- 시트: `public/assets/anim/player-*.png` (char/weapon 분리, 총 ~2.9MB)
- 크레딧 소모 누적: 약 290

## 다음: 몬스터 3종 확장 (사용자 승인됨)

**방침**: 8방향(원거리라 충분, 용량 절약), 클립 = idle2 + walk + 공격 1종. 정적 캘리브레이션 절차 준수.

1. **클린 레퍼런스 생성** (manifest 추가됨):
   - `enemy-ghoul-rig`: 직립 자세 구울 (기존은 돌진 자세라 리깅 불리). 무기 없음.
   - `enemy-archer-rig`: 활 없는 해골 궁수 + `weapon-bow` 별도 (왼손 부착).
   - `enemy-brute-rig`: 맨손 브루트 + `weapon-maul` (대형 철퇴 — 사슬 플레일은 강체 부착 시 부자연스러워 교체).
2. **파이프라인 실행**: 몬스터 3종 병렬 백그라운드 + 무기 2종 norig.
   - 구울 공격: Attack(4) 후보 — 웅크린 체형이라 오히려 적합할 수 있음, 실패 시 97.
   - 브루트 공격: Sword_Judgment(102, 오버헤드 헤비). 궁수: 활 사격 액션 ID는 라이브러리 문서에서 재조회 필요.
   - **구울 리깅 실패 가능성** (비휴머노이드 체형): 실패 시 해당 몬스터만 기존 정적+프로시저럴 유지.
3. **정적 캘리브레이션** 각 몬스터 → 8방향 시트 캡처 (char/weapon) → `public/assets/anim/<kind>-*.png`
4. **렌더러 통합**: 적 종별 시트 로드, 상태 전이(이동=walk, 정지=idle, 공격 휴리스틱: 궁수는 shoot 이벤트, 근접은 플레이어 근접 시 attack 클립), 시체 페이드는 기존 로직 재사용(마지막 텍스처 복제).
5. 검증(방향 정합·게임 크기)·배포·회고.

**예상 크레딧**: 몬스터 3종 ~150 + 무기 2종 ~70 = **~220** (당초 150 안내에서 무기 분리 설계 비용 추가). 실측치 보고 예정.
