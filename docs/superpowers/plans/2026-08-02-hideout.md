# Seedcore 은신처 (D7) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 게임 시작점을 은신처(허브)로 바꾸고, 코어 삽입 장치→포탈 진입이라는 물리적 루프를 만든다.

**Architecture:** 은신처는 수제 고정 타일맵(생성기 미사용, 몬스터 0)으로 기존 Dungeon 구조를 재사용해 렌더러 변경을 최소화한다. 스테이션 4개는 근접+E 상호작용으로 기존 시장 패널의 섹션을 모드별로 노출한다. 포탈은 코드 드로잉 이펙트 + 충돌 진입.

**설계 확정:**
- 시작·귀환 지점 = 은신처. 클리어 후 R = 귀환, 사망 시 R = 재도전 / H = 귀환(코어 소모 유지)
- 장치: 보유 코어 [삽입] 또는 [탐사](무작위 시드, 무료) → 패널 닫히고 포탈 생성 → 걸어 들어가면 진입
- 던전 안에서는 패널을 열 수 없다 (M 단축키는 은신처의 상인 호출로 축소)
- 스테이션: 장치(삽입·탐사) / 상인(구매·판매·코드 입력) / 보관함(열람·코드 복사) / 대장간(강화)
